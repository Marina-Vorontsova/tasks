# Одна задача в день

Минималистичное веб-приложение по техническому заданию: пользователь хранит локальный список задач, а приложение показывает одну случайную активную задачу на активный день.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не требуются.

Данные сохраняются в `localStorage` текущего браузера.

## Файлы

- `index.html` — страница приложения.
- `styles.css` — минималистичный интерфейс.
- `app.js` — логика задач, архива, выбора задачи на день и локального хранения.
